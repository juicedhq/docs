---
title: List Customers
description: List your customers, or find the one with a given email.
openapi: GET /v1/customers
---

Without filters, this lists your active customers, oldest first, 50 at a time. Pass `next_cursor` back as `cursor` to get the next page. When `next_cursor` is `null`, you've reached the end.

With `email`, it returns the customer using that email, or an empty list. Archived customers are included here, since their email can't be used for a new customer.
