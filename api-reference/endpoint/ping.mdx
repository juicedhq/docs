---
title: Submit a Ping (Legacy)
description: The deprecated unversioned ping endpoint. Use the v1 endpoint for new integrations.
openapi: POST /ping
---

<Warning>
This endpoint is deprecated and frozen. Build new integrations on [Submit a Ping](/api-reference/endpoint/v1/ping), and see [Migrating from the legacy API](/api-reference/introduction#migrating-from-the-legacy-api) for how to move over.
</Warning>

The response has one of two shapes. Non-vendor sources get `ping_id`, `message` and `bids` when the ping went through matching or used a test-mode zip. Vendor sources always get `message`, `price` and `ping_id`, and so does any ping answered before matching (duplicate, quota reached, or rejected).
